# 26Home-Icons
Official Online Icon Packs Repository for the **26Home** iOS Tweak.

## Icon Pack Format
Each icon pack is distributed as a compressed `.tar.gz` archive containing themed icon folders matching 26Home's themes (`Light`, `Dark`, `ClearLight`, `ClearDark`, `DarkNS`).

### Metadata (`index.json`)
The `index.json` catalog powers the in-app Icon Pack Browser inside 26Home preferences.
